# Credit Risk and Fraud Analytics

A beginner-level banking analytics project built with Python. It explores loan default risk and simple transaction fraud patterns using **synthetic data only**.

## Project goals

- Explore loan applicant and loan-related data.
- Check missing values, duplicates, unusual values and target imbalance.
- Compare default rates across applicant and loan groups.
- Review previous applications and repayment history.
- Explore basic transaction patterns that may be linked to fraud.
- Build and evaluate a baseline logistic regression model.
- Explain results in a short report for hypothetical business, risk, operations and IT stakeholders.

## Dataset note

All records, customer profiles, transactions and outcome labels are generated for practice. They are not real bank or customer records. The notebook uses a fixed random seed so the synthetic datasets can be reproduced.

## Analysis included

- Data inspection and data quality checks
- Missing-value and duplicate checks
- IQR-based outlier review
- Default-rate and class-imbalance analysis
- Univariate, segmented and bivariate analysis
- Correlation analysis within outcome groups
- Charts using Matplotlib and Seaborn
- Basic probability and statistical testing
- Introductory logistic regression and model evaluation
- A small linear algebra example
- Illustrative expected-loss calculation and risk recommendations

## Run the project

Use Python 3.10 or later. From the project folder, install the packages:

```bash
pip install -r requirements.txt
```

Open `Credit_Risk_EDA_Trimester1.ipynb` in Jupyter Notebook, JupyterLab or Google Colab and run all cells from the top. The notebook's first data-generation section recreates the CSV files in the `data/` folder. If you run it locally, keep the notebook and folders in the structure shown above.

## Tools and skills

Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, scikit-learn, exploratory data analysis, data cleaning, data visualization, probability, statistics, logistic regression and credit-risk concepts.

## Limitations

This is a learning and portfolio project, not a production lending or fraud system. The model uses synthetic data, so its results do not show how it would perform on real customers. Any loss-given-default value or review threshold in the notebook is an illustrative assumption. Real lending decisions need suitable real-world validation, legal and fairness checks, security controls and human oversight.
